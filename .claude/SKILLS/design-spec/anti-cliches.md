# Clichés prohibidos

Si un diseño incluye alguno, se reemplaza por una alternativa propia de la dirección
creativa antes de aprobarlo.

| Cliché | Alternativa en esta dirección |
|--------|-------------------------------|
| Foto circular + "Hola, soy X 👋" + botón "Contáctame" | Hero código → UI con datos reales |
| Barras o porcentajes de habilidades ("React 85%") | Habilidades demostradas en proyectos concretos, etiquetas mono con contexto |
| Fila de logos de tecnologías sin contexto | Tecnologías asociadas a cada proyecto o experiencia |
| Grid de cards idénticas sin jerarquía | Proyecto destacado + variaciones de tamaño, spotlight y bordes luminosos |
| Timeline vertical genérico con puntos | Experiencia con reveals y detalle técnico (stack, impacto real de cv.md) |
| Typewriter con frases rotativas ("I'm a developer / designer…") | Efecto scramble/decode con un único mensaje significativo |
| Partículas genéricas tipo particles.js | Grid fino con glow sutil que reacciona al cursor |
| Gradiente morado-rosa de plantilla | Gradientes dentro de la paleta azul/negro |
| Secciones About / Skills / Projects / Contact con estructura idéntica | Ritmo visual variado entre secciones |
| Ilustraciones stock o avatares 3D genéricos | Elementos gráficos derivados de código, grids y luz |
| Lorem ipsum, testimonios o métricas inventadas | Solo contenido de `docs/cv.md` |
| Animaciones en todo sin jerarquía | Un momento protagonista por pantalla; el resto sobrio |
